## Listing text

### Title

```
Crates: Rust crate browser
```

### Short description

```
Search, explore and read Rust crates from crates.io. Unofficial client.
```

### Full description

```
Crates is an unofficial Android client for crates.io, the Rust community's package registry. Browse, search and read about Rust crates from your phone or tablet.

EXPLORE
• New crates, most downloaded, just updated and most recent downloads, like the crates.io home page
• Popular keywords and categories
• Total downloads and number of crates on the registry

SEARCH
• Search by name, keyword or category
• Sort by relevance, all-time downloads, recent downloads, recent updates or newest
• Keeps loading results as you scroll

CRATE PAGES
• The crate's README, readable in light and dark mode
• Downloads, license, minimum Rust version, edition and size
• Copy "cargo add" or the Cargo.toml line with one tap
• Versions with dates and download counts, yanked versions marked
• Dependencies, dev-dependencies and build-dependencies; tap one to open it
• Owners, categories and links to the homepage, docs.rs and the repository

YOUR CRATES
• Log in with GitHub, the same way as on crates.io
• See the crates you own

MADE FOR EVERY SCREEN
• Bottom navigation on phones, a navigation rail and side-by-side crate pages on tablets
• Light, dark or system theme
• Shows the last loaded pages when you are offline

Crates talks to crates.io directly. There are no ads, no analytics and no servers of our own. The source code is on GitHub: https://github.com/randspace0/crates

Crates is not affiliated with or endorsed by crates.io or the Rust Foundation. "Rust" and "crates.io" are trademarks of the Rust Foundation.
```

### Data safety answers

The app has no backend, analytics or crash reporting. Requests go to crates.io and GitHub, plus any image hosts a README embeds, only when the user opens that screen. App data is excluded from backups and device transfers.

- **Does the app collect or share user data?** Yes, minimal:
  - *Personal info → User IDs*: the crates.io user ID and login are fetched from crates.io and **stored on device**. The ID is sent back to crates.io to list the user's crates. Purpose: App functionality. Not shared.
  - *App activity / Authentication*: the crates.io session cookie, sent only to crates.io.
- **Encrypted in transit?** Yes (HTTPS only)
- **Can users request deletion?** Yes: sign out, or clear app data / uninstall. Nothing is kept server-side by the app
- The GitHub password is typed into GitHub's own page in a WebView; the app never reads it

## Trademarks

"Rust" and "crates.io" are Rust Foundation trademarks. The listing keeps them out of the app name and icon, says the app is unofficial, and uses the names only to describe what the app connects to (see the [Rust trademark policy](https://foundation.rust-lang.org/policies/logo-policy-and-media-guide/)). The icon is original pixel art (crates on a pallet), not the crates.io logo.
